# JH WT (private)

Private test builds of the Jungle Hawks WT line for Pingu and invited testers. **Contains War Thunder-derived files (c) Gaijin Entertainment - never make this repo public or share the release files.**

Builds are release-asset zips (manifest.json + parts). The JH Installer pulls them when you are signed in to GitHub with access to this repo; otherwise it falls back to the public 1946 base.
